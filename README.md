# Telegram Watch

Компактный клиент Telegram для часов с круглым экраном (личный аккаунт через MTProto/TDLib).

## Что уже есть
- Экран входа (номер телефона → код → облачный пароль, если включён)
- Список чатов (круглый layout)
- Просмотр сообщений (текст) + отправка текста
- Фоновый сервис для получения сообщений

## Что нужно донастроить
- `app/src/main/java/.../Config.kt` — вписать свои `API_ID` и `API_HASH` с https://my.telegram.org
- Фото/голосовые — следующий этап (заготовка есть в `MessageAdapter`, рендер типов `photo`/`voiceNote` нужно доделать)

## Сборка
Сборка полностью автоматическая через GitHub Actions — см. `.github/workflows/build.yml`.
При каждом push в `main` система:
1. Собирает нативную библиотеку TDLib из официального исходного кода (`tdlib/td`)
2. Собирает APK
3. Кладёт готовый `app-debug.apk` в раздел **Actions → (последний запуск) → Artifacts**

Первая сборка может занять 20-40 минут (компиляция TDLib из исходников) и теоретически может
потребовать донастройки — путь к файлам, генерируемым TDLib, иногда отличается между версиями.
Если сборка упадёт — пришли мне (Claude) текст ошибки из лога Actions, поправим.

## Установка на часы
Скачай `app-debug.apk` из Artifacts на телефон, затем через ADBAppControl установи на часы
(Install APK → выбрать файл).
